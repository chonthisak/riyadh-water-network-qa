# QGIS project setup
Open ../data/network.gpkg, choose pipes_raw, sources, valves and qa_before. Set project CRS to EPSG:32638. Categorize qa_before by code and label with code if useful. Save as riyadh-water-network.qgz here, with relative paths enabled. A saved QGIS project is intentionally not supplied without GUI validation. See ../docs/GETTING_STARTED_TH.md.
